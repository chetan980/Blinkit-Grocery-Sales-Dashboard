# Blinkit Grocery Sales Dashboard

## Project Overview
This project presents an interactive Power BI dashboard analyzing Blinkit grocery sales data.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Features
- Total Sales
- Average Sales
- Number of Items
- Average Rating
- Outlet Analysis
- Item Type Analysis
- Fat Content Analysis
- Outlet Size and Location Analysis

## Project Files
- `Blinkit_Grocery_Sales_Dashboard.pbix` – Power BI dashboard
- `Dashboard.png` – Dashboard preview
